
BloodLine is a crisis-resilience platform for Singapore's national blood supply. While existing tools like DonateBlood help individuals schedule appointments, no system anticipates shortages, mobilises donors in emergencies, or brings first-time donors back.
BloodLine fills that gap with three modes. Predict forecasts shortages 14 days ahead so donors are recruited before stocks run critical. Surge activates targeted, geo-tiered alerts to eligible donors when crises hit, replacing slow public appeals. Retain closes the emotional loop with personalised impact, milestones, and squads — turning one-time donors into lifelong contributors.
One platform, three modes, built so Singapore never runs critical on blood again.

01 PREDICT

14-day shortage forecast (Bayesian model, per blood type)
Regional risk map — bubble size = donor deficit, colour = probability
Blood type heatmap — all 8 types × 14 days
Real-time national need indicator on donor home screen (ok / low / urgent / critical)
Recommended actions for HSA (critical / urgent / low)
Type detail page — 14-day supply outlook for any specific type
Hospital demand input — procedures feed the forecast model
Targeted push notifications to eligible donors before shortage hits

02 SURGE

Break-glass activation (requires dual HSA sign-off)
Tiered geo-alerts — 5km → 15km → island-wide
Multi-channel outreach — push, SMS, WhatsApp
Donor surge alert screen — red banner, single CTA, "Why you got this" explainer
Auto-opens extra blood bank slots
Live monitoring — donors notified, responses, bookings per bloodbank
Hospital emergency draw request → triggers surge consideration
Snooze option (2h) to prevent donor fatigue

03 RETAIN

Impact card — "Your unit supported 3 patients at NUH"
Lifetime stats — donations, lives reached, volume given
Annual donation history chart
HSA milestone badges — Bronze (10) → Silver (25) → Gold (50) → Honorary (100)
Squads with leaderboard rankings (workplace, alumni, RC)
Donation streak tracker
Eligibility countdown — "you can donate again in X days"
Donor pool segmentation for HSA — active / dormant / at-risk / lapsed

04 SCHEDULE

3-step booking flow — pick time → confirm (health pre-check) → success
"Bring a friend" post-booking prompt
Drives near you — filter by type + distance, RSVP
Mobilise my workplace — 4-step flow (pick org → set time → review invite → live tracker)
HSA-suggested time slots based on bloodbank capacity
WhatsApp + email invite preview
Community drive approval queue (HSA side)
Drive requests scored by forecast fit
